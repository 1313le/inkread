墨读 InkRead 随包字体授权说明
================================

本目录的 15 个 .woff2 都是「子集化后的改作版本」（OFL 定义里的 Modified
Version），由 scripts/build-fonts.py 调用 fontTools 的 pyftsubset 生成：只
删除本应用字符集之外的码位，未改动任何字形轮廓，并保留原字体的版权声明
（name ID 0）与授权信息（name ID 13/14，源文件本身带有的那些）。

按 SIL Open Font License 1.1 第 (3) 条，改作版本不得使用原字体的 Reserved
Font Name，所以族名统一改为 InkRead Serif / InkRead Sans / InkRead Kai /
InkRead Latin，不再以 "Noto ..."、"Source ..."、"LXGW WenKai"、"Crimson
Pro" 作为字体名对外呈现；字体内部 name ID 1/2/3/4/6 与文件里的 CSS 族名同步
改名，并在 name ID 10 写明来源。

关于 name ID 13
--------------

思源两份的 Google Fonts 原件本身不带 name ID 13（许可证描述），因此许可证
全文以本文件随包分发，符合第 (2) 条「每一份副本须包含上述版权声明与本许可
证；可作为独立文本文件……随附」。
